# Sai Ram Suvarna — Portfolio

Static cinematic personal brand site (HTML / CSS / vanilla JS).

## Stack

- `index.html`, `style.css`, `script.js`
- GSAP + ScrollTrigger + Lenis (CDN)
- Deploy: Vercel static (`vercel.json`)

## Local preview

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173
